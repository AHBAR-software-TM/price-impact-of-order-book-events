# price-impact-of-order-book-events
Replication and Cross-Market Analysis of Cont, Kukanov, &amp; Stoikov (2014)  Empirical evaluation of Order Flow Imbalance (OFI), linear/nonlinear price impact, and market depth scaling across Hyperliquid crypto perpetuals (BTC, ETH, SOL, HYPE, DOGE) and U.S. equities (AAPL, AMZN).
